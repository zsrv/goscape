Engine cheat commands¶

Built into the server engine (modules/world/handlers_game.go). Gating varies by command: most require staff mod level 2, 3, or 4, and some additionally require a non-production world; a few (like ::say) are ungated. See modules/world/handlers_game.go for each command's exact gate.
