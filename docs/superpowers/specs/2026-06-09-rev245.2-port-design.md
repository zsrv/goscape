## Deviation policy

The 245.2 pin is authoritative — **including where it reverts 244-only
fixes**:

1. **Hiscores `banned_until` gate removed** (244's `ccc263c7` is absent
   from 245.2). goscape follows: the gate comes out of
   `modules/login/hiscore.go`. Banned players update hiscores again, as
   upstream 245.2 ships.
2. **Friends staff threshold loosened** (`staffLvl > 1` → `> 0`): staff
   level 1 now populates `playerStaff`. The goscape test pinning the old
   threshold is updated to the new contract (hard rule: a test pinning
   superseded TS behavior gets updated, not preserved).

Existing PORTING-EXCEPTION markers carry forward unreviewed unless a 245.2
hunk touches their site. New deviations get new tracker rows.

## Risks (ordered)

1. **Reference-cache regeneration surprises** — Content moved
   (`e5d0282e..cbcfe670`) along with the engine, so pack-output deltas mix
   content changes with the two new config codes. Mitigation: generate the
   cache as the FIRST Phase-2 task; the byte-diff loop plus `.sym` anchors
   isolate compiler-input vs packer-logic differences (Arc-26 method).
2. **Script-opcode shift fallout** — four `*QUEUEVARARG` values move; any
   hardcoded numeric use outside the generated map would silently misroute.
   Mitigation: regenerate the pin from TS source, grep numeric literals of
   the old values.
3. **Renumber typos** — 80+ wire IDs change by hand; a single transposition
   only surfaces at smoke time. Mitigation: regenerate pin tables from the
   TS file mechanically (script or careful agent + reviewer cross-check
   against `git show 3c16994c:…` line-by-line), not by eyeballing the diff.
