# PORTING-CLOSED.md

Historical record of closed parity work between goscape (Go) and the
upstream LostCityRS Engine-TS TypeScript reference. Snapshot taken
post-Arc-22 (May 2026): the open-deviations tracker (`../PORTING.md`)
has been slimmed to active items only, with this document preserving
the audit lineage + shipped-fix citations for future reference.

**For active items, see `../PORTING.md`.**

This file is append-mostly: rows here have shipped or been closed as
PARITY / FALSE-POSITIVE. Don't reopen them without verifying the
underlying code hasn't drifted.

## Legend

- ✅ **PARITY** — cold-read confirmed, 0 REAL-GAPs against TS source
- 🚧 **DEVIATION** — known divergence; may or may not need a fix
- ❌ **GAP** — TS has the feature, Go doesn't (or stub-only)
- 🔒 **SECURITY** — exploit surface; fix priority
- ⚡ **PERF** — performance hotspot or allocation pressure
- 📋 **BACKLOG** — open work with shippable spec (NAI ticket usually attached)
- ➕ **EXTENSION** — goscape adds capability beyond TS (e.g., telemetry, gRPC bridges)
